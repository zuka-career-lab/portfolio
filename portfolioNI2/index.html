01

経歴サマリー

大学入学から現在まで。並行していた役割は、同じ時期の中に書いています。

  1. 2019年4月〜2023年3月名城大学 農学部 生物資源学科幼い頃からの夢「ドラゴンボールの仙豆をつくる」ために、品種改良の研究者がいる農学部へ(第一・第二志望は不合格、第三志望で入学)。入学初日に実現は難しいと知り、私立大学に通わせてくれた両親への責任から「学費の全額回収」を目標に切り替え、講義・学内講座・課外活動を使い切りました。
  2. 2020年7月〜2023年3月(在学中、3社が一部並行)長期インターン3社コロナ禍で授業とアルバイトが止まった時期を、実務経験を積む機会にしました。
    • トリイ株式会社(2020年7月〜2022年3月):子ども向け新規事業の立ち上げ
    • ミテモ株式会社(2021年9月〜2023年3月):八丈島の親子向けプログラムの企画と、地元への引き継ぎ
    • 株式会社イノベスト(2021年10月〜2023年3月):大学のリーダーシップ科目(受講者120名・全15回)の運営
  3. 2023年4月ミテモ株式会社 入社(インソースグループ、従業員30名程度)数か月の就職活動でキャリアを決めることに違和感があり、半年以上インターンした3社すべてから内定をもらった中で、最も合うと感じた会社を選びました。「仙豆で世界は変えられなかったが、教育でなら変えられる」と考えたからです。
  4. 2023年4月〜9月研修の運営と、採用イベントの企画(並行)研修の準備から当日の運営、報告書づくりまでを担当しました。並行して担当した採用イベントは、次の採用の章で紹介します。
  5. 2023年10月〜2025年9月法人営業(研修・ワークショップ事業)顧客の課題を直接聞くために営業へ移りました。2024年10月〜2025年9月は、社内のバリュー刷新に向けたチームのリーダーも兼ねていました。
  6. 2025年10月〜プロダクトマネージャー(エンゲージメント領域)社内最年少の24歳で就任。足りない力を自覚し、学び直してから着任しました。
  7. 2026年10月〜現在地域共創事業 プロジェクトマネージャー自治体が主催する人材育成・地域活性化の事業を担当しています。
02

採用:新卒採用インターンシップの企画・運営

入社1年目(2023年4月〜)に、親会社インソースの案件を自ら志願して担当しました。

何をつくったか

  • 学生が採用担当者の立場を疑似体験する「人事体験ワークショップ」を提案しました
  • 企画の段階で複数の案を4コマ漫画にし、決裁者の人事に諮る前に、受講者・内定者・若手社員の反応を確かめました
  • 経営層・人事と、内定者から入社3年目までの社員に話を聞き、採用ペルソナ(採りたい学生の人物像)をつくりました

採用の流れ(ファネル)で見ると

母集団形成就活サイト en-courage の人気イベントランキングで2か月連続2位(2024年1月版ほか)
参加学生がワークショップに参加し、面接官・学生・観察者の3つの立場を体験
説明会・エントリーへ立ち上げ期(2023年度)は参加者の約57%が会社説明会への参加を希望。2024年7月以降の回では43.8%がエントリーを希望
内定このプログラムを経て6名
入社2名
9.64 / 10立ち上げ期(2023年度)の満足度・対面オンラインは 8.41 / 10
8.85 / 102024年7月〜2025年5月の満足度の平均アンケート回答388件。8点以上が約9割
継続中2023年7月の初開催から、毎月いまは時間を短くし、運営の手間を減らした形で続いています

学生・内定者との関わり

立ち上げ(0→1)から定着・拡大(1→10)までを担当しました。初回の登壇、マニュアル化、担当の引き継ぎ、開催後の改善です。イベントの中に会社説明の時間を組み込み、学生がその日だけで学べ、同時に会社を知ってもらえる構成にしました。

募集とランキングで母集団をつくり、ワークショップで候補者体験を設計し、説明会につないで選考への動機づけをする。採用の一連の流れを、企画から内定・入社まで回した経験です。

法人営業:新規顧客部門で売上1位

2023年10月〜2025年9月。企業の人事・経営層に研修を提案し、受注後は研修が職場で生きるかまで見ました。

99件・約5,120万円新規顧客部門の売上1位2024年10月〜2025年9月の1年間、個人の担当実績
約200件顧客開拓から効果検証まで一貫して担当した研修2023年11月〜2026年3月の累計(2025年10月以降を含む)

受注のあと、研修が職場で生きるかを測る

  • 研修後アンケートに、満足度だけでなく「職場でどれだけ生かせそうか」を測る項目を加え、効果の確認と改善に使いました
  • 日本ステリ株式会社の中堅社員研修(218名・全10回)では、回ごとの結果をもとに次の回の内容を直しました(事例記事)

提案の準備

大手製薬メーカーの社長直下の提案では、関連書籍8冊を読み込んだうえで、全体構想と8つのカリキュラムを企画しました。受注には至りませんでしたが、この提案の姿勢が社長に評価されました。

人に動いてもらうときの進め方

  1. まず、相手と一対一の関係をつくる
  2. 相手の興味・関心を知る
  3. 相手の制約や事情を聞く
  4. こちらの依頼と、相手の関心・動ける範囲の折衷案をつくる
相手の課題を聞き、提案し、決めていただく流れは、候補者に会社の魅力を伝えて意思決定を後押しする採用の仕事と同じ型です。
04

組織づくり・カルチャー

会社の価値観づくりに関わった経験です。

  • 2024年10月〜2025年9月、バリュー刷新プロジェクト(全体6名、リーダーは社長)の前段階として、自社らしさを言葉にする4人のチームを率いました
  • 代表やエース社員にインタビューし、言葉になっていなかった考え方や判断の基準(暗黙知)を言葉にして、社内に広げました
  • 同じ聞き方を顧客企業でも使い、社員へのインタビューで、人事担当者も把握していなかった現場の声を提案に組み込みました
  • 2025年10月からは、組織風土づくりやMVV(ミッション・ビジョン・バリュー)刷新などの課題に対する提案を担当しています
この経験は、採用広報やカルチャーの発信、入社した人が定着する組織づくりに生かせます。

AI活用・業務の自動化

手作業や属人化を、ツールと仕組みで減らしてきました。

  • このページは、生成AI(Claude Code)を使って構成・制作しました
  • 学生時代に運営を任された大学の授業で、出席や学習状況の集計を Slack と Google Apps Script で自動化しました

  • 工程表を互いに確認し合う仕組みを入れ、手戻りを前月の約3割に減らしました
  • Microsoft Copilot を日々の業務で毎日使っています
  • Power Automate を使った自動化も重ね、こうした業務改善で社長賞を3回受賞し、殿堂入りしました
  • 学生時代に GeekSalon の WebExpertコースを修了しました(4人のチームでWebアプリを開発)

プロジェクト推進:プロダクトマネジメントと地域共創

チームや関係者をまとめて、事業を前に進めた経験です。

プロダクトマネージャー(2025年10月〜)

  • 社内最年少の24歳で就任(同じ役職のほかの社員は、いずれもキャリア7年目以上)。エンゲージメント領域の研修を企画・提案するチームを統括しました
  • 自分を含む3名の営業チームのリーダーとして、チームの予実と営業の進み具合を管理しました。メンバー2名はいずれも10歳ほど年上で、自分の報告先は社長です
  • チーム目標を約112%で達成し、ほかのチームの未達分も補いました(チームの受注金額6,160万円)
  • 新規のお客様には初回からできるだけ訪問することを自分で決め、訪問件数を前年同期(2024年10月〜2025年3月)の14件から、この半期は58件に増やしました。対面で深く聞いたことで、新規で550万円の大型案件を受注しました

地域共創事業 プロジェクトマネージャー(2026年10月〜現在)

  • 事業部(20名)で、自治体が主催する人材育成・地域活性化の事業の企画と運営を担当しています
  • 担当している事業:和歌山県(地域課題に取り組む企業の成長支援。経営者向けの研修・交流会)、名古屋市「なごや学生社会課題解決プログラム」(学生が市の職員と社会課題に取り組む。令和8年度は8月〜12月)、茨城県「農村活性化プロデューサー育成講座(INSPIRE IBARAKI)」(県からの委託。令和8年度は2026年9月〜2027年3月)
  • 茨城県の事業では、先進地域への視察を企画しました。視察先の選定と交渉、終日のプログラム、移動や昼食の手配までを担い、自治体職員を含む12名を引率しました。受講者の満足度は100%(10名)、視察先からは「いいプログラムだったから謝礼はいらない」と言っていただきました

大切にしている価値観

仕事の進め方の根っこにある4つです。

  • まずやって、あとで直す完璧な案を待たず、早く形にして反応を見ます
  • 改善を、続ける一度うまくいったやり方も、結果を見て直し続けます
  • ゼロから学び、最後は仕組みにする自分がいなくなっても回り続けるように
  • そなえよ、つねにボーイスカウトの標語。いつ何が来ても動けるよう、準備を欠かしません

趣味:雨水とソーラー電源で動く自動水やり装置の自作、コーヒー
